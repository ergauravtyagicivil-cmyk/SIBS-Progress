Live copy for the team

Publish your figures to a GitHub repository. Anyone with the page link sees the latest set the next time they open or refresh it — nothing to email round.

Setting it up the first time
  1. Create a repository on GitHub, for example sibs-progress. It has to be public for free Pages hosting, so keep client-identifying detail out of the register and get the project manager's nod first.
  2. In that repository: Settings → Pages → deploy from branch main, folder / (root).
  3. GitHub → Settings → Developer settings → Fine-grained tokens. Give it access to this one repository only, with Contents: Read and write. Copy the token into the box above.
  4. Fill in the user and repository above, then press Download the page file and upload the resulting index.html to the repository.
  5. Press Publish update. That writes data.json and your figures go live.
  6. Send colleagues https://<user>.github.io/<repository>/. They get a view-only dashboard, timeline and alignment map.
  7. To edit from the live page yourself, open the same link with #edit on the end and paste your token in once.
